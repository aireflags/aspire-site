# 调试登录问题

## 当前问题

登录后跳转到 `http://localhost:3000/welcome?error=AccessDenied`

## 已添加调试日志

已在 `auth.ts` 的 `signIn` callback 中添加了调试日志，将显示：
- 用户尝试登录的邮箱地址
- 提取的邮箱域名
- 允许的域名列表
- 是否授予访问权限

## 查看日志

1. **重启开发服务器**：
   ```bash
   npm run dev
   ```

2. **查看终端输出**：
   - 尝试登录时，终端会显示调试信息
   - 查看实际的邮箱地址和域名
   - 确认域名是否在允许列表中

3. **检查控制台**（浏览器开发者工具）：
   - 打开浏览器开发者工具（F12）
   - 查看 Console 标签页
   - 查看 Network 标签页中的请求

## 常见问题

### 问题 1: 邮箱域名不匹配

**症状**：日志显示域名不在允许列表中

**可能原因**：
- 使用的是 Google Workspace 账户（例如 `@yourcompany.com` 而不是 `@gmail.com`）
- 邮箱格式异常

**解决方案**：
- 检查日志中显示的实际域名
- 如果需要在允许列表中添加该域名，编辑 `auth.ts` 中的 `ALLOWED_EMAIL_DOMAINS` 数组

### 问题 2: 服务器未重启

**症状**：修改代码后仍然使用旧的逻辑

**解决方案**：
- 停止开发服务器（Ctrl+C）
- 重新启动：`npm run dev`

### 问题 3: 缓存问题

**症状**：即使重启后仍然有问题

**解决方案**：
- 清除浏览器缓存和 cookies
- 或者使用隐私/无痕模式测试
