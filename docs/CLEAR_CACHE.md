# 清除浏览器缓存指南

## Microsoft Edge

### 方法 1: 硬刷新（最简单）
- 按 `Ctrl + Shift + R` (Windows) 或 `Cmd + Shift + R` (Mac)
- 这会强制浏览器重新加载所有资源，忽略缓存

### 方法 2: 清除浏览数据
1. 按 `Ctrl + Shift + Delete` (Windows) 或 `Cmd + Shift + Delete` (Mac)
2. 选择时间范围："过去一小时" 或 "所有时间"
3. 勾选：
   - ✅ 缓存的图像和文件
   - ✅ Cookie 和其他站点数据（可选）
4. 点击"立即清除"

### 方法 3: 开发者工具清除
1. 按 `F12` 打开开发者工具
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

## Safari

### 方法 1: 硬刷新
- 按 `Cmd + Option + R` (Mac)
- 或按 `Cmd + Shift + R`

### 方法 2: 清除缓存
1. 按 `Cmd + Option + E` 清除缓存
2. 或前往：Safari > 设置 > 高级 > 显示开发菜单
3. 然后：开发 > 清空缓存

### 方法 3: 私有浏览窗口测试
1. 按 `Cmd + Shift + N` 打开新的私有窗口
2. 访问 `http://localhost:3000`
3. 这样可以完全绕过缓存

## 注意事项

如果清除缓存后图标仍然不显示，问题可能不是缓存，而是：
- 字体文件没有正确加载
- CSS 配置问题
- Next.js 构建问题

在这种情况下，请检查浏览器开发者工具中的 Network 标签页，查看字体文件是否成功加载。
