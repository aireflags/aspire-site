# 功能背景、目标、范围、非目标

## 1. 项目背景

### 项目概述
**Alex Brokerage Enterprise** 是一个面向高级金融经纪人的企业级仪表板应用，旨在提供 AI 驱动的市场洞察和集成的客户管理工具。

### 业务背景
- **目标用户**：金融经纪人（特别是高级经纪人）
- **使用场景**：日常业务操作、客户管理、市场分析、合规审计
- **核心价值**：通过 AI 助手提高工作效率，整合多个业务工具到统一平台

### 技术背景
- **平台**：Web 应用（移动端优先设计）
- **部署**：Vercel（静态部署）
- **AI 能力**：集成 Google Gemini AI 作为智能助手

## 2. 功能目标

### 2.1 核心功能目标

#### Home 页面（企业工具中心）
- **目标**：作为应用的主入口，展示所有可用的企业工具
- **功能**：
  - 显示用户信息（头像、姓名、角色）
  - 展示企业工具卡片网格（10 个工具）
  - 提供通知中心入口
  - 快速访问各个业务模块

#### AspireAI 页面（AI 助手）
- **目标**：提供智能对话助手，帮助经纪人快速获取信息和建议
- **功能**：
  - AI 驱动的对话界面
  - 常见问题快速入口
  - 实时响应生成
  - 对话历史管理
  - 语音输入入口（UI 已准备，功能待实现）

#### Settings 页面（设置中心）
- **目标**：提供应用配置和用户偏好设置
- **功能**：
  - 个人信息管理
  - 安全和隐私设置
  - 通知偏好
  - 区域和语言设置
  - 支持中心入口
  - 登出功能

#### Portfolio 页面（资产组合）
- **目标**：展示资产管理和投资组合信息
- **状态**：代码已存在，但未在路由中注册（可能是预留功能）

### 2.2 用户体验目标
- **响应式设计**：移动端优先，最大宽度 `max-w-md`
- **一致性**：统一的视觉风格和交互模式
- **性能**：快速加载和流畅的交互体验
- **可访问性**：遵循基本的无障碍设计原则

### 2.3 技术目标
- **现代化技术栈**：React 19 + TypeScript + Vite
- **类型安全**：充分利用 TypeScript 类型系统
- **可维护性**：清晰的代码组织和组件结构
- **可扩展性**：便于添加新功能和工具

## 5. 技术约束

### 5.1 技术选型约束
- **前端框架**：React 19（已固定）
- **构建工具**：Vite（已固定）
- **部署平台**：Vercel（已固定）
- **路由模式**：HashRouter（适合静态部署）

### 5.2 环境约束
- **浏览器支持**：现代浏览器（ES6+）
- **网络要求**：需要访问 Gemini API
- **API 限制**：依赖 Gemini API 的可用性和速率限制

### 5.3 设计约束
- **移动端优先**：最大宽度限制为移动端尺寸
- **暗色主题**：当前仅支持暗色主题
- **图标系统**：使用 Material Symbols（需网络连接）

## 6. 项目边界

### 6.1 本项目的职责
- 提供统一的 UI 界面和导航
- 集成 Gemini AI 提供对话功能
- 展示企业工具入口（UI 层面）
- 提供基本的设置界面

### 6.2 不属于本项目的职责
- 具体的业务逻辑实现（如 CRM、市场数据等）
- 用户认证和权限管理
- 数据存储和持久化
- 第三方业务系统的集成

### 6.3 依赖的外部服务
- **Google Gemini API**：提供 AI 对话能力
- **Material Symbols CDN**：图标资源
- **Tailwind CSS CDN**：样式框架
- **Vercel**：部署和托管服务
